使用说明与已知限制

流程：点左侧键帽（白色主键或蓝色 Fn 副键）→ 在「① 实际按法」里手写按键组合，或点「录制实际按法」在空中飞鼠上按一次 → 选「替换为」的输出 → 保存 → 打开右上角总开关。

① 实际按法可以手写：直接输入 Ctrl+Win+Left、Alt+Tab、AltGr、Q；也支持原始键码 0x51、VK 229，以及照着事件流写 usage 0x0014（HID Usage）。修饰键写前面、最后一个是主键，例如 Ctrl+Alt+Q；别名 Command / Super / Meta / Windows 都当作 Win，RightAlt / RAlt 当作 AltGr。Fn 是空中飞鼠内部层键，Windows 收不到，所以 Fn+Q 不能手写 —— 先录制一次 Fn+Q，看事件流里实际发出的组合，再照着写。手写不依赖键盘捕获，捕获关着也能编辑规则；下面会显示解析出的 VK / Scan / HID 字段，确认无误再保存。「匹配方式」选「忽略额外修饰键」时，同时多按了别的修饰键也照样触发。

键盘捕获开关（右上角）：这是独立于「映射总开关」的总闸。开启＝安装低级键盘钩子，程序才能看到、拦截、替换按键；关闭＝卸载钩子，所有按键原样放行，程序不再记录 / 拦截 / 注入任何按键，映射自然也不生效。选择会写进 mappings.json，重启后保持。若遇到「按任何键都没反应」，先关闭捕获再点「释放卡住的键」：通常是某个修饰键（AltGr / Win 等）残留在按下状态，把所有输入都变成了组合键；程序现在也会自动检测并解除这类卡键。快捷键 Ctrl+Alt+Shift+F11 可一键关闭捕获（关闭后钩子已卸载，需用界面按钮重新开启），Ctrl+Alt+Shift+F12 只切换映射总开关。也可直接访问 /api/capture?on=0 或 ?on=1 开关。

录制期间所有按键都会被程序吞掉，不会输入到别的窗口，8 秒无操作自动结束。想换成另一个键，可用「录一个目标键」。

单独按修饰键（AltGr / Alt / Ctrl / Shift / Win）：按下时事件流会显示「单独按下，松开即录到该键」，松开该键才完成录制；事件流里写「无修饰键」只是说没有别的修饰键同时按住，不是报错也不是没录到。若同时按住 Ctrl 等，录制结果会带 Ctrl。

AltGr → Win：点第四行 AltGr 键帽 → 录制实际按法并在空中飞鼠上按一下 AltGr（会录成 AltGr，不是 Alt 或 Ctrl+Alt）→ 在「替换为」的修饰键 / Win 分组点「Win 键（按住生效）」→ 保存。这样按住 AltGr 时 Win 保持按下，可以配 R / E / D 使用；直接输入 Win 只会点按一下。Windows 为 AltGr 附带的假 Ctrl 会被自动抵消。

AltGr 的识别依据是「右 Alt」（VK_RMENU，或带 EXT 标志的 Alt），所以物理键盘的右 Alt 也会一起被映射，左 Alt 不受影响。总开关关闭时程序不会改动任何按键行为。按一下 AltGr，可在事件流里看到 AltGr 与原始 VK 0xA5 / Usage 0x00E6；若显示的是别的值，说明空中飞鼠发的键码不同，需要改识别条件。

组合键（Ctrl + Win 等）：把某键换成 Win / Ctrl 这类修饰键的规则会透传同时按住的其它修饰键：先按住 Ctrl 再按 AltGr，系统里就是 Ctrl + Win，还能继续接方向键。程序不再为了「避免污染输出」提前松开 Ctrl；只有普通替换（如换成 Esc）才会先松开触发组合里的修饰键。同一键若另有精确组合规则（如 Ctrl+Q → Esc），精确规则优先。

三键同按失效怎么判断：先按住三个键，看右侧「组合键诊断」的峰值键数。达到 3 说明键都到了引擎，那问题在 Windows 侧 —— 不少 Win 组合是系统保留快捷键（Ctrl+Win+←/→ 切换虚拟桌面、Win+L 锁屏、Ctrl+Alt+Del 安全序列），任何应用层注入都无效。若峰值只有 2，说明是空中飞鼠 / 键盘硬件的多键回滚（2KRO）：同时按三个键时第三个根本没发出来，软件层无法补救；解决办法是把整个组合绑到一个键上（自定义组合键里写 Ctrl+Win+Left），用一次单键发出完整组合。另外「假 Ctrl」抵消逻辑已收紧：只要同时按着 Shift 等其它键，就不会误把你真正按住的 Ctrl 松开。

右下角浮条实时显示当前一起按住的键与系统等效组合：蓝色是真实按下的修饰键，紫色是映射规则注入并保持的替换键；右侧「当前一起按住的键」卡片还有来源拆解。排查组合键时先按住键看这里。

Fn 层：空中飞鼠上的 Fn + 白键在 Windows 里通常表现为 Alt/Ctrl + 字母之类的组合键，录制结果会如实显示，不用自己猜。

作用范围：低级键盘钩子无法区分按键来自哪个设备，所以映射是全局的，物理键盘上同名按键同样会被替换。关掉总开关、按 Ctrl+Alt+Shift+F12，或直接退出程序即可立刻恢复，不写注册表。

捕获不到的键：空中飞鼠部分非标准键（返回键 / 独立音量键）会被 Windows 蓝牙键盘驱动在内核层丢弃，任何应用层工具（含本工具、AutoHotkey）都收不到；要做到设备级隔离或捕获这些键需要签名过滤驱动，本工具刻意不引入。

配置保存在程序目录的 mappings.json，可导出备份；程序不常驻时映射不生效。
